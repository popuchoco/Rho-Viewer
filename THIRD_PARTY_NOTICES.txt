1. KartRider-File-Reader / KartLibrary
---------------------------------------

Source: https://github.com/xpoi5010/Kartrider-File-Reader
License: GNU General Public License, version 3 (GPL-3.0)
Local source directory:
third_party/Kartrider-File-Reader/

Rho Viewer Portable uses the local KartLibrary source as the Rho archive
decoding backend. In particular, the local file
third_party/Kartrider-File-Reader/src/KartriderLibrary/Encrypt/RhoKey.cs
contains the RhoKey vector table used by the decoder. The released program
does not fetch this file from GitHub at runtime.

The KSV summary view calls the upstream KartRecord/KSVInfo structures. The
OGG and FLAC metadata summaries in this application are local, lightweight
container readers layered on top of decoded resource bytes; they do not copy
an external audio decoder.

The full GPL-3.0 text is included in LICENSE. The source package also keeps
the upstream LICENSE file beside the local KartLibrary source.
