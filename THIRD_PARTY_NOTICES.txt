1. KartRider-File-Reader / KartLibrary
---------------------------------------

Source: https://github.com/xpoi5010/Kartrider-File-Reader
License: GNU General Public License, version 3 (GPL-3.0)
Local source directory:
third_party/Kartrider-File-Reader/
Bundled KartLibrary AssemblyVersion/FileVersion: 24.1.31.1
Upstream revision anchor: 37fab6415360afa83e8034f8cedb2cc6766d2fe0 (2024-02-21)
Revision evidence and limits: see third_party/Kartrider-File-Reader/UPSTREAM.md.

Rho Viewer Portable uses the local KartLibrary source as the Rho archive
decoding backend. The KSV summary calls its KartRecord/KSVInfo reader. In
particular, the local file
third_party/Kartrider-File-Reader/src/KartriderLibrary/Encrypt/RhoKey.cs
contains the RhoKey vector table used by the decoder. The released program
does not fetch this file from GitHub at runtime.

The `.bml` preview is an independent, bounded parser based on the public
`src/KartriderLibrary/Xml/BinaryXmlTag.cs` and
`src/KartriderLibrary/IO/BinaryReaderExt.cs` field layout (UTF-16LE
length-prefixed strings, attributes, and recursive child tags). It does not
call the upstream unbounded recursive BML reader or copy its implementation.
The preview is generated XML-like output; the original `.bml` payload remains
binary.

The OGG and FLAC metadata summaries in this application are local,
lightweight container readers layered on top of decoded resource bytes; they
do not copy an external audio decoder.

The vendored reader has downstream changes for legacy Rho block-checksum
validation and Rho5 ordered duplicate-entry handling, exact decompression
length, and per-entry MD5 validation. These changes remain subject to GPL-3.0.

The full GPL-3.0 text is included in LICENSE. The source package also keeps
the upstream LICENSE file beside the local KartLibrary source.

DotNetZip 1.16.0 dependency removal:
The vendored reader previously used DotNetZip's Ionic.Zlib.ZlibStream for
legacy Rho/Rho5 compression and decompression. Those call sites have been
migrated to the .NET System.IO.Compression.ZLibStream and the DotNetZip
PackageReference has been removed. A source audit found no ZipFile or
ZipEntry.Extract archive extraction calls in the application, vendored reader,
or tests. NVD describes CVE-2024-48510 as a path traversal in ZipEntry.Extract:
https://nvd.nist.gov/vuln/detail/CVE-2024-48510
This notice records the migration rationale; confirm the current package graph
with NuGet restore/audit output. Any further change to these zlib paths must be
validated against real Rho, Rho5, and LPK corpora.
